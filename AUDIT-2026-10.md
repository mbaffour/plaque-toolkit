# Audit 2026-10 — findings and disposition

A second code audit of the Plaque Toolkit was carried out in October 2026 against
**v1.1.0** (commit `cd7b75b`, the release of 2026-10-13). It covered the ground the
September audit ([`AUDIT-2026-09.md`](AUDIT-2026-09.md)) had not: the desktop app
(`app/`), the statistics packages (`plaque_stats/`), the Precise/ML engine, the web app,
packaging, and every user-facing document, as well as a fresh pass over the two engine
modules. It raised the findings **PT-23 … PT-85** below and re-assessed the eleven
deferred items of the previous round.

Work was done on branch `claude/audit-2026-10`. The version was **not** bumped and no
release was cut; that is the maintainer's call (see "Numbers that change" and "Owner
decisions").

## The freeze that preceded it

Before any change, v1.1.0 was frozen inside the repository:
[`releases/v1.1.0/`](releases/v1.1.0/MANIFEST.md) records the SHA-256 of every source
file, the exact library versions, and the SHA-256 of the 99 CSV/JSON outputs that v1.1.0
produces on the bundled `Test_plates` in every engine mode. Every fix below was checked
against that oracle.

## The rule that governed every fix

Same as last time: **no fix was allowed to move a default Published-mode measurement
value.** After all changes, the full baseline was re-run (`releases/v1.1.0/run_baseline.sh`)
and compared: **93 of 99 output files are byte-identical**, including every
`data-green-*.csv` in Current, Published, `--upstream-exact`, Sensitive and watershed
mode, and every turbidity `plaques_all.csv` / `per_phage.csv`. The six that differ do so
only by **added columns** (`summary.csv`: `MM_CALIBRATED`, natural plate order;
`qc.csv`: `NATIVE_MAX`, `FULL_SCALE`, `FLAT_APPLIED`, `DARK_APPLIED`); no existing cell
changed.

Where a fix *does* change a number on inputs the baseline does not contain, it is listed
under "Numbers that change" in [`CHANGELOG.md`](CHANGELOG.md) and marked ⚠ in the table.

---

## Disposition

Severity: P0 = wrong published number or data loss; P1 = wrong result or crash in a main
path; P2 = edge path or misleading output; P3 = cosmetic. "Verified" means the auditor
reproduced it by running code before it was fixed, and a test now pins it.

## Numbers that change

Listed for the record; `CHANGELOG.md` carries the user-facing version.

1. **Turbidity on 16-bit input** (PT-27): detection now matches `plaque_size_tool.py` on the same file. Any plaque set from a 16-bit capture measured with 1.1.0 should be re-run. 8-bit input is unchanged (verified on all 17 bundled plates).
2. **Turbidity with `--blank` plus `--flat`/`--dark`** (PT-28): the flat/dark correction now actually reaches the OD. Blank-only and lawn-relative runs are unchanged.
3. **Batch tab, Published engine** (PT-33): no longer runs with `-small`; results now equal the Measure tab and the CLI.
4. **App / editor, Published engine, `DIAMETER_MM`** (PT-30): 0.01 mm on about 3 % of plaques, now equal to the CLI.
5. **Precise** (PT-36): seam-straddling fragments dropped.
6. **Statistics** (PT-41, PT-42, PT-44): LONG input is no longer pooled across metrics; unequal-variance data gets Welch/Games–Howell; grouped p-values are Holm-adjusted.

None of these touches `plaque_size_tool.py --published` output.

## Owner decisions

1. **Release.** The fixes above warrant **1.1.1** (or 1.2.0 given the new columns and flags). `_version.py`, `CITATION.cff`, `.zenodo.json` and the two installer scripts need the bump; then tag.
2. **PT-17 `TURBIDITY_REL`** and **PT-80 sRGB luma order**: both move Published or default-OD numbers; both have a documented opt-in path.
3. **PT-63 negative-control figures** and **PT-15**: archive one blank-plate run under `validation/` and quote it everywhere.
4. **PT-68 / PT-16 licences**: one SPDX id for the PlaqSeg weights, documented provenance, and "AGPL-3.0-only" in `CITATION.cff` / `.zenodo.json` if inherited from ultralytics.
5. **Web app deployment**: pin the Dockerfile clone to a tag and show the version and engine label in the UI.
6. **PT-1 default flip, PT-7 table date**: still open from the previous round.

## How to re-verify

```bash
python -m pytest                      # 85 tests (53 from 1.1.0 + 32 for this audit)
python plaque_app.py --smoke          # engine acceptance gate -> SMOKE OK
REPO=$PWD SCRATCH=/tmp/pt-check VENV_PY=$(which python) releases/v1.1.0/run_baseline.sh
cd /tmp/pt-check/baseline-v1.1.0 && shasum -a 256 -c $OLDPWD/releases/v1.1.0/SHA256SUMS-baseline-outputs.txt | grep -v ': OK$'
```

The last command must list only the six additive files named above.
